# CasinoX v3.4

Base funcional: CasinoX v3.3.

## Referência visual
A tela `assets/reference/lucky-rabbit-reference.png` é usada como referência visual do Lucky Rabbit.

## Mudanças
- Tela do jogo reestruturada para seguir a composição da referência.
- Fundo da referência fica atrás da interface; não é usado dentro dos rolos.
- Removido o card/personagem antigo que sobrepunha a arte.
- Máquina 5x3 preservada como componente funcional próprio.
- Botão GIRAR permanece no layout durante o giro e não desaparece.
- O handler duplicado da versão anterior foi substituído por chamada ao motor de giro original.
- Botão GIRAR recebeu proporções, tipografia, gradiente e subtítulo inspirados diretamente na referência.
- Cabeçalho, saldo, estatísticas e controles reorganizados de forma responsiva.
- Lucky Rabbit usa a referência enviada; os demais jogos usam seus backgrounds específicos existentes até que sejam fornecidas artes-modelo próprias para cada animal.
- Versão visível: v3.4.
- URL pública permanece fixa: https://paulojrmgb.github.io/casinox/

## Observação
Não foi gerada uma nova imagem para a conversa. A referência existente foi incorporada ao projeto como asset visual.
