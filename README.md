# CasinoX v0.1

Protótipo de cassino social com créditos virtuais.

## Conteúdo

- Home responsiva
- Catálogo de jogos
- Slot machine
- Roleta
- Blackjack simplificado
- Crash demonstrativo
- Promoções
- Ranking
- Perfil local
- Saldo salvo no navegador

## Publicar no GitHub Pages

1. Crie um repositório chamado `casinox`.
2. Envie os arquivos para a raiz.
3. Abra Settings → Pages.
4. Em Build and deployment selecione:
   - Deploy from a branch
   - Branch: main
   - Folder: / (root)
5. Clique em Save.

Esta versão utiliza somente créditos virtuais.

Não possui dinheiro real, depósitos ou saques.
